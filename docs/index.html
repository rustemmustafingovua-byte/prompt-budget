prompt-budget

What does your system prompt actually cost on every single request?

Every request re-sends the system prompt, the tool schemas and the rules file. On a metered model that is the dominant cost; on a free tier it is what burns the daily pool. This measures all of it before you ship it.

View on GitHub npm README

What it does

Token estimateRules file, code blocks, every section.
Tool schemasWhich tools eat the context.
Cost per request and per sessionWith your own prices.
Actionable adviceWhat to cut, what to move into a skill.

Usage

Measure a rules fileprompt-budget AGENTS.md
Include the toolsprompt-budget AGENTS.md --tools tools.json --calls 50
Custom pricesprompt-budget AGENTS.md --price-in 0.1 --price-out 0.5

How it works

  1. The file is split into sections; each section is measured separately.
  2. Tool schemas are measured as JSON, which is what actually reaches the model.
  3. The verdict compares the total against what a serious agent needs.
